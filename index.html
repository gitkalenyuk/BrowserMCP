Браузер, яким керуєте ви і ваш AI

BrowserMCP — це звичайний браузер на Chromium для щоденної роботи. Різниця в тому, що будь-яку його функцію може викликати AI-агент: Claude Code, Codex або ваш власний скрипт. Він відкриває вкладки, читає сторінки, натискає кнопки й записує мережевий трафік.

Для чого

Агент працює у вашому браузері, а не в окремому headless-процесі

Агент бачить ті самі вкладки, логіни й профілі, що й ви. Сторінку він читає як короткий текст із посиланнями на елементи, тому токенів іде в рази менше, ніж на скріншоти.

AI-агент керує браузером

Claude Code, Codex або будь-який MCP-клієнт підключається одним рядком. Агент отримує понад 240 команд: вкладки, клік, введення тексту, читання сторінки, трафік.

Записав раз, запустив тисячу

Запишіть дії на сторінці, і браузер перетворить їх на TypeScript-скрипт. Потім запускайте його по CSV чи Excel у кілька потоків, за розкладом або з вебхука.

Трафік і профілі під контролем

Перехоплення запитів, підміна відповідей і експорт HAR. Окремі профілі зі своїм проксі, мовою й відбитком браузера, вбудований блокувальник реклами.

Можливості

Кожна функція — це команда API

Усі команди зібрані в одному реєстрі. З нього браузер сам будує MCP-інструменти, REST API з OpenAPI, WebSocket JSON-RPC і TypeScript SDK, тож через будь-який інтерфейс доступно те саме.

Вкладки й навігація core

Відкрити, закрити, заморозити, групи вкладок. Кожен агент отримує свою кольорову групу, і чужі вкладки йому заблоковані.

Читання сторінок core

Знімок дерева доступності зі стабільними посиланнями @7:e3, пошук елементів, дії й пакети дій, різниця між знімками, режим читання.

Передача людині core

Якщо треба увійти в акаунт або пройти CAPTCHA, агент просить вас зробити це в його вкладці й чекає.

Трафік net

Запис запитів і WebSocket-кадрів, правила (блок, редирект, заголовки, моки), точки зупинки, повтор запиту, генерація коду з API.

Запис і кодогенерація record

Лог дій людини й агента перетворюється на TypeScript-скрипт. Також можна записати відео екрана (потрібен ffmpeg).

Масові запуски run

Черга, паралельні потоки, повтори, пауза й продовження, експорт у CSV, Excel, JSON чи SQLite. Коли сайт змінився, AI сам пропонує виправлення селектора.

Профілі й прихований режим profile stealth

Окремі cookies, кеш, проксі й мова для кожного профілю. Відбитки браузера, емуляція пристроїв, пули проксі.

Щоденний браузер data

Закладки, історія, паролі, імпорт із Chrome, PDF і MHTML. Блокувальник реклами Brave з EasyList і вимкнення JS, картинок чи шрифтів для окремих сайтів.

Вбудований AI і термінал ai

Бічна панель із Claude Code, Codex або API-провайдерами (Anthropic, Gemini, OpenAI-сумісні). Поруч термінал PowerShell, cmd чи Git Bash.

Сповіщення ui

Сповіщення в інтерфейсі браузера, у Windows, у Telegram (з кнопками відповіді) і через вебхук. Підказки для переходу за посиланнями в стилі Vim.

Встановлення

Від архіву до агента за п'ять хвилин

Інсталятора немає: розпакували й запустили. Усе, що браузер зберігає, лежить у папці data поруч із програмою, тож його можна носити на флешці.

Завантажте архів

Відкрийте останній реліз і завантажте BrowserMCP-0.1.0-win64.zip (≈ 210 МБ). Розпакуйте його в будь-яку папку, наприклад C:\Tools\BrowserMCP.

Розпаковуйте повністю. Якщо запускати програму прямо з архіву, вона не знайде своїх бібліотек.

Запустіть browsermcp.exe

Програма поки не підписана сертифікатом, тому під час першого запуску Windows може показати синє вікно SmartScreen.

  1. Натисніть «Докладніше» (More info).
  2. Натисніть «Виконати в будь-якому разі» (Run anyway).

Відкриється звичайне вікно браузера. Поки воно відкрите, API працює на 127.0.0.1:47800 і доступне тільки з вашого комп'ютера.

Підключіть AI-агента

Виберіть свій клієнт. Шлях C:\Tools\BrowserMCP замініть на свою папку.

Якщо браузер уже відкритий, виконайте в терміналі:

claude mcp add --transport http browsermcp http://127.0.0.1:47800/mcp

Щоб агент сам запускав браузер, коли він потрібен, підключіть його через stdio:

claude mcp add browsermcp -- C:\Tools\BrowserMCP\browsermcp.exe mcp-stdio

Перезапустіть Claude Code і попросіть, наприклад: «Відкрий github.com у BrowserMCP і скажи, що на головній».

Додайте в %USERPROFILE%\.codex\config.toml:

[mcp_servers.browsermcp]
command = 'C:\Tools\BrowserMCP\browsermcp.exe'
args = ["mcp-stdio"]

Codex запустить браузер сам, коли агенту знадобиться перший інструмент.

Додайте інструменти, коли знадобляться

Щоб не засмічувати контекст агента, MCP за замовчуванням віддає тільки групи core і system. Решту підключайте в адресі:

claude mcp add --transport http browsermcp "http://127.0.0.1:47800/mcp?toolsets=core,net,record,run"

Групи: core, profile, net, record, script, run, data, stealth, ai, ui, system.

Скрипти

Автоматизація, яка не ламається від першої зміни на сайті

  • Скрипти на TypeScript лежать у data/scripts і працюють в окремому процесі V8. Якщо скрипт впаде, браузер продовжить працювати.
  • Масовий запуск: рядки беруться з CSV, JSON або Excel, кожен рядок обробляється окремо, є повтори, пауза й продовження.
  • Самовідновлення: якщо селектор перестав знаходити елемент, запуск ставиться на паузу, AI пропонує виправлення, і після вашого підтвердження робота йде далі.
  • Тригери: розклад cron або вебхук із підписом HMAC.
// data/scripts/title.ts
const { tab } = await browser.tabs.open({ url: inputs.url });
await browser.nav.wait({ tab, for: "load" });
const t = (await browser.tabs.list()).tabs
  .find((x) => x.id === tab)?.title;
browser.output({ url: inputs.url, title: t });
# запустити по таблиці у 4 потоки
run.start {script: "title",
  data: {csv_path: "C:/urls.csv"},
  parallel: 4, retries: 1}
run.export {id, to: "xlsx"}
Питання

Що варто знати

Чим це відрізняється від Playwright MCP чи розширень для Chrome?

BrowserMCP — це сам браузер, а не надбудова над ним. Агент працює у ваших вкладках і профілях, бачить сторінку текстом, а не скріншотами, і має доступ до трафіку, профілів, запису й масових запусків. Ті самі команди доступні через MCP, REST, WebSocket і SDK.

Це безпечно? Хтось ззовні може керувати моїм браузером?

API слухає тільки 127.0.0.1 і перевіряє заголовки Host та Origin, тому сайти, відкриті в браузері, не можуть до нього звертатися. Ззовні комп'ютера він недоступний.

Версія 0.1.0 рання: пісочниця процесів Chromium поки вимкнена, а паролі в data зберігаються без шифрування. Для банків і важливих акаунтів краще поки користуватися основним браузером.

Де зберігаються мої дані?

Усе зберігається в папці data поруч із browsermcp.exe: профілі, історія, закладки, скрипти, записи й налаштування у звичайному JSON. Іншу папку можна задати параметром --data-dir. Щоб перенести браузер, скопіюйте всю папку.

Чи можна запускати без вікна, на сервері?

Так: browsermcp.exe --headless --window-size 1280x800. Вкладки рендеряться поза екраном, скріншоти, відео й введення працюють. Процес не завершується, поки не надійде команда system.quit.

Є версія для macOS чи Linux?

Поки тільки Windows. Версію для macOS заплановано. Код відкритий, тож зібрати його можна й самому, інструкції є в README.

Як зібрати з вихідного коду?

Потрібні Rust (MSVC), Visual Studio Build Tools із C++ і Windows 11 SDK, CMake, Ninja, Node 22+ та pnpm. Далі виконайте:

cargo xtask doctor
pnpm install
pnpm -C ui build
cargo xtask run

Під час першої збірки завантажиться CEF (≈ 500 МБ). Портативний архів збирає команда cargo xtask dist.

Відео не записується

Для запису відео потрібен ffmpeg.exe, у архів він не входить. Покладіть його поруч із browsermcp.exe або додайте до PATH.
